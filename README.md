# C Programming Foundations

Collection of foundational C programs written and tested during Semester 1 (ECE, Saranathan College of Engineering).

## Programs Included:
- **01_leap_year.c**: Determines if a given year is a leap year using conditional logic.
- **02_calculator.c**: Menu-driven arithmetic calculator using switch-case statements.
